# Drop generated images here

Save your AI-generated images into this folder using these filenames:

| Filename | Used for | Prompt in |
|----------|----------|-----------|
| `hero.jpg` | Hero banner | `PROMPTS.md` → section 1 |
| `problem.jpg` | Problem / context | `PROMPTS.md` → section 2 |
| `pipeline.jpg` | How it works | `PROMPTS.md` → section 3 |
| `team.jpg` | Team / collaboration | `PROMPTS.md` → section 4 |
| `impact.jpg` | (optional) Impact / classroom | `PROMPTS.md` → section 5 |

Use **16:9** aspect ratio. Then swap the placeholders in `index.html` for `<img>` tags referencing these files.
